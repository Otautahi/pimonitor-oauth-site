Private infrastructure · Personal project

Understand your home server. Without exposing it.

PiMonitor Diagnostics is a self-hosted monitoring and reporting utility for a Raspberry Pi. It tracks system health, project services, and device availability, and can publish a small set of sanitized diagnostic reports to an owner-controlled Google Drive folder.

Personal use · No public dashboard
01 / Observe

System and service health

Summaries of availability, resource usage, monitored projects, and selected Bluetooth sensor health.

02 / Diagnose

Private diagnostic reports

Field-allowlisted JSON snapshots and incident summaries help the owner identify failures and recovery events.

03 / Control

Restricted Drive access

Google Drive access uses the drive.file scope for files the application creates or opens with authorization.

What this website is — and isn't

This is a public information page for the PiMonitor Diagnostics Google OAuth application. It is not the PiMonitor interface, a login page, a device-control service, or a public endpoint into a home network. The monitoring dashboard and diagnostic data remain in the owner's private environment.

Read how Google data is handled in the Privacy Policy.
